# PrimeKG Data Directory

Place the real PrimeKG `kg.csv` file here when you want to work with PrimeKG-derived biomedical subgraphs:

```text
data/primekg/kg.csv
```

The app does not download PrimeKG automatically and normal startup does not require this file.

Large PrimeKG files are intentionally ignored by Git. Keep only this README and `.gitignore` in the repository.
